A Unix-Like Kernel in HTML.

SB3_UNIX is an experimental kernel built entirely in HTML. It reimagines the foundations of operating system design through the lens of the modern web stack.

Current Status

"It works... slowly."

We are currently moving from Kernel 1 to Kernel 2. While Kernel 1 implemented basic Unix-like philosophies, Kernel 2 aims for a more flexible architecture with optimized performance.
